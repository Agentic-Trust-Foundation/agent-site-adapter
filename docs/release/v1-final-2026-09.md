# Agent Site Adapter V1 Final Release

**Release:** V1  
**Date:** 2026-09-21  
**Status:** Final

## Included

- architecture and trust model;
- service identity and identity binding;
- authentication model;
- discovery/interoperability;
- capability model;
- authorization, consent and delegation;
- authority evidence binding;
- request lifecycle and error semantics;
- versioning/compatibility;
- semantic conformance suite;
- profile framework;
- Web HTTP profile;
- ecosystem integration profiles;
- Agent-Pay integration profile;
- security release review;
- profile-neutral reference implementation;
- V1 protocol specification.

## V1 boundary

V1 freezes semantic contracts and the generic HTTPS/JSON binding plus profile identifiers. External ecosystems retain ownership of their native wire protocols. No central registry is required.

The release does not claim:
- production cryptographic verification in the reference package;
- payment-provider integration;
- regulatory certification;
- universal credential/token serialization;
- browser-extension-only implementation.

## Conformance gate

A V1 implementation is conformant only if:
1. it passes the semantic security suite;
2. it implements the selected profile's mandatory requirements;
3. it enforces the ATF authority boundary;
4. it preserves Agent-Pay non-expansion;
5. it rejects incompatible/security-ambiguous inputs.

## Post-V1

Further protocol changes require a new version or an explicitly compatible extension.
