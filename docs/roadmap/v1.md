# Site Adapter Roadmap

## V1 completion status

**V1 FINAL — 2026-09-21**

Phases 0–10 established the architecture, security semantics, conformance suite and semantic reference implementation.

### Phase 11 — Integration Profiles

**Complete**

Defined:
- V1 profile framework;
- Web HTTP and OAuth HTTP;
- MCP and A2A integration boundaries;
- Commerce;
- Booking;
- SaaS/API;
- Enterprise;
- Healthcare;
- Cloud/infrastructure;
- Agent-Pay profile.

### Phase 12 — Agent-Pay Integration Profile

**Complete**

Defined:
- financial handoff;
- authorization evidence binding;
- authorization-context hashing;
- amount/currency/payee binding;
- approval correlation;
- idempotency;
- provider-neutral lifecycle;
- non-expansion invariant.

### Phase 13 — Security Review and Release Candidate

**Complete**

Reviewed identity, discovery, authentication, authorization, delegation, consent, replay, downgrade, SSRF, sensitive data and cross-repository boundaries. Residual deployment risks are documented.

### Phase 14 — V1 Release

**Complete**

Frozen:
- V1 semantic authorization contract;
- generic HTTPS/JSON binding;
- profile identifiers;
- conformance requirements;
- Agent-Pay handoff contract.

Native wire formats of OAuth, MCP, A2A and UCP remain owned by their respective protocols.

### Phase 15 — V2 Research Backlog

**Complete**

Recorded non-normative research areas for richer federation, advanced delegation, verifiable claims, cross-domain trust, assurance/reputation, advanced agent-to-agent authorization and governance.

V2 research does not alter V1 behavior.

## Definition of Done

V1 is complete only when the release specification, profile documents, conformance suite, reference implementation and security review are mutually consistent.

See `docs/protocol/site-adapter-v1.md`.
